# GRIMGLOW Volume 1 — ChatGPT Project Setup (Per Issue)

One ChatGPT Project per issue for generating comic panel art. Each project gets the issue script as a file upload plus character reference images rotated by who appears in the current scene.

**Free tier limit: 5 files per project.** File 1 is always the script. Files 2–5 rotate based on which characters are in the scene you're generating. The full character list below each project block shows all available references — upload the ones you need for the current scene.
